Grid Map Path 项目启动说明
 
一、项目简介
 
本项目为网格地图路径规划算法演示系统，支持多种路径规划算法的可视化对比与交互操作，启动后通过浏览器即可访问使用。
 
二、运行环境要求
 
- 操作系统：Windows 10/11（64位）

- 必备软件：Anaconda 或 Miniconda（建议Python 3.11及以上版本）

- 网络环境：首次启动需联网安装依赖包
 
三、启动步骤
 
方案一：一键启动（推荐，无需手动配置）
 
1. 将项目压缩包解压至 无中文、无特殊字符 的路径（示例：D:\GridMapPath）；

2. 打开解压后的项目根目录，双击运行 启动项目_通用版.bat；

3. 等待脚本自动完成：虚拟环境创建 → 依赖包安装 → 项目启动（首次启动约1-2分钟，取决于网络速度）；

4. 启动成功后，浏览器会自动打开项目页面（地址：http://127.0.0.1:7860），即可开始使用。
 
方案二：手动启动（备用，适用于脚本启动异常时）
 
1. 解压项目包至无中文路径，打开「Anaconda Prompt」终端；

2. 执行命令创建并激活虚拟环境：
conda create -n py311_env python=3.11 -y
conda activate py311_env

3. 进入项目根目录（示例路径需替换为实际解压路径）：
cd D:\GridMapPath

4. 安装依赖包：
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

5. 启动项目：
python main.py

6. 打开浏览器，输入 http://127.0.0.1:7860 访问。
 
四、常见问题解决
 
1. 脚本提示“未找到Anaconda”：
 
- 原因：未安装Anaconda/Miniconda，或环境变量未配置；

- 解决：安装Anaconda后，将其 condabin 和 Scripts 目录添加到系统环境变量「Path」，重启电脑后重试。
 
2. 依赖安装失败：
 
- 原因：网络不稳定或镜像源访问异常；

- 解决：关闭脚本重新双击启动，脚本会自动重试；或手动执行方案二中的依赖安装命令。
 
3. 浏览器无法打开/端口被占用：
 
- 原因：7860端口被其他程序占用；

- 解决：修改 main.py 中 demo.launch() 的端口参数（示例：demo.launch(server_port=7861)），同时修改脚本中 start http://127.0.0.1:7861，保存后重新启动。
 
4. 项目启动后功能异常/报错：
 
- 原因：依赖包版本不兼容；

- 解决：删除项目根目录下的 requirements.txt，重新双击脚本，或手动执行 pip install --upgrade gradio numpy matplotlib 升级核心依赖。
 
五、注意事项
 
1. 项目路径务必避免中文和特殊字符（如空格、括号、中文标点等），否则可能导致启动失败；

2. 首次启动因需创建环境和安装依赖，耗时较长，请耐心等待，不要中途关闭终端；

3. 启动成功后，终端窗口请勿关闭，关闭终端会导致项目停止运行；

4. 若需关闭项目，先关闭浏览器页面，再关闭终端窗口即可。
