# Grid Map Path 使用说明

本文介绍如何安装、启动和使用网格地图路径规划演示程序。

## 1. 环境准备

- Python 3.11 或更高版本
- 能访问 Python 包索引的网络，用于首次安装依赖

建议在仓库根目录创建独立虚拟环境，避免影响系统 Python。

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r grid_map_path/requirements.txt
python grid_map_path/main.py
```

也可以双击 `grid_map_path/start_windows.bat`。该脚本会使用 PATH 中的 Python 检查并安装依赖，然后启动应用。

### macOS 或 Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r grid_map_path/requirements.txt
python grid_map_path/main.py
```

启动成功后，程序会尝试打开浏览器，也可以手动访问 <http://127.0.0.1:7860>。程序运行期间请保留终端窗口；关闭终端或按 `Ctrl+C` 可停止服务。

## 2. 界面操作

界面左侧是设置和运行按钮，右侧显示地图或算法结果。

### 创建地图

1. 在“选择地图类型”中选择简单地图、随机地图或迷宫地图。
2. 设置行数和列数，范围为 5 到 20。
3. 选择随机地图时，可以调整障碍物密度；该设置对另外两种地图不生效。
4. 点击“更新地图”。地图会重新生成，并将起点、终点重置到地图内部的默认位置。

地图外圈是障碍。随机地图的障碍只在内部区域生成；随机结果可能没有可行路径。示例迷宫用于演示规则障碍，不保证每种尺寸下都存在通路。

### 设置起点和终点

坐标从 0 开始，格式为“行、列”，例如 `(1, 2)` 表示第 2 行、第 3 列。先填写起点行和列，再点击“更新起点”；终点同理。超出当前地图范围的坐标会被限制到地图边界。若选中的位置是障碍，该格会被改成可通行格。

### 运行算法

- 选择 BFS、DFS 或 A*，点击“运行单个算法”查看对应路径和搜索区域。
- 点击“运行所有算法”查看三种算法的指标汇总和对比图。
- 地图颜色说明：障碍为深色，探索区域以浅蓝色显示，路径为红线，起点为绿色，终点为红色。

## 3. 算法与指标

地图采用上下左右四方向移动，不允许斜向移动；每一步代价相同。

| 算法 | 说明 |
| --- | --- |
| BFS | 按距离逐层搜索；在当前等代价地图上保证找到最短路径，但可能展开较多节点。 |
| DFS | 沿一条分支深入搜索；可以找到可行路径，但不保证最短。 |
| A* | 使用曼哈顿距离引导搜索；在当前四方向、等代价设定下保证找到最短路径。 |

界面指标的定义：

- **路径长度**：路径经过的移动步数，不是路径坐标点的数量。起点和终点相同时为 0。
- **探索节点数**：算法实际展开的格子数，包含起点；尚未展开、仅被发现的格子不计入。
- **运行时间**：当前进程中算法搜索调用的耗时。地图较小或运行时间很短时，计时容易受到系统负载影响；微小差异不一定代表稳定的速度优势。

若找不到路径，算法会返回不可达结果。可以改用简单地图，或重新生成随机地图。

## 4. 常见问题

### 提示找不到 `python`

安装 Python 3.11 或更高版本，并在安装时启用加入 PATH 的选项。安装后重新打开终端，再执行启动命令。

### 依赖安装失败

确认网络可用，并在仓库根目录重新运行：

```bash
python -m pip install -r grid_map_path/requirements.txt
```

macOS 或 Linux 环境可将 `python` 换成 `python3`。

### 页面打不开或提示端口占用

确认启动终端仍在运行，并访问 <http://127.0.0.1:7860>。如果 7860 端口被其他程序占用，先关闭占用该端口的程序，再重新启动本应用。

### 随机地图没有路径

这是可能出现的正常结果。点击“更新地图”重新生成，降低障碍物密度，或切换到简单地图。
